# Recursive training of WGANs and VAEs
In this project we explore the phenomenon of model collapse. 
Specifically, we train multiple generations of machine learning models (WGANs and VAEs), where each generation is trained on image data generated by the previous generation of models. We then look at the degradation in model quality, as a function of generation number.

## Usage

The main training loop is found in `main.py`. Run 
```
python main.py --help
```
for guidance on usage. Each type of model (VAE and WGAN) has a corresponding config file, located in `/configs/`. Training parameters and hyperparameters can be set there. 

The plots are generated using files found in `/analysis/`. They can be run with
```
python -m analysis.{script_name}
```
For instance, 
```
python -m analysis.pixel_intensity
```
will generate some pixel intensity distribution plots.
